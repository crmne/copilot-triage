Done now shows what finished today, and Sign off only holds closures nobody has weighed in on yet.

## New

- **Done is today's work.** The daily sweep archives everything already in Done, so the column shows what closed or merged since the morning. Set `board.archive_after_days` to keep finished work longer; it was 7 days before. By @crmne.
- **Drag an open item to Done to put it away.** The sweep archives it without closing the issue or pull request, and brings it back when it is reopened or someone comments. Until now the sweep moved such a card straight back. By @crmne.
- **Cards move to Done the moment work finishes.** The Copilot Triage workflow in [crmne/github-automation](https://github.com/crmne/github-automation) now runs when issues and pull requests close, so a merged or closed item no longer waits for the daily sweep. Add `closed` to the `issues` and `pull_request_target` types in your own workflow to get the same. By @crmne.

## Fixed

- **No more closure proposals you already answered.** A duplicate or resolved issue went to Sign off even after it was reopened or after you commented on it, asking you to confirm a closure you had already rejected. Triage now proposes a closure only when no person has weighed in, and the sweep places existing stale proposals again: back to the reporter when you spoke last, to you when they did. By @crmne.
- **A proposed closure says so.** Its next step now starts with "Close it if you agree:", so it is clear what signing off an issue means. By @crmne.

Verified with RuboCop, 314 specs, and a dry-run sweep of the real board: the reopened zapfast issue moved from Sign off to Do, and the omarchy-hyprmoncfg issue where the maintainer had asked for a pull request moved to Their move.
