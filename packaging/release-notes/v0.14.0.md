Triage keeps your board current after the Copilot allowance runs out, on a fallback model that costs about a cent a day.

## New

- **A fallback when Copilot is spent.** With `fallback-api-key` set, triage checks the remaining Copilot premium requests before each run. When fewer than 50 are left and overage is off, it uses `openai/gpt-oss-120b` through OpenRouter instead (`fallback-provider` and `fallback-model` change it). A fallback run only places the card on the board and posts nothing. In our evaluation, gpt-oss judged pull requests and cards as well as the default model but replied less reliably, 16 of 23 cases overall, for about one cent for the whole run. By @crmne.

## Fixed

- **gpt-oss works through OpenRouter.** OpenRouter's hosts of gpt-oss answer a required tool call with an empty error, so every run failed. Triage now lets OpenRouter models choose their tools, and reminds any model that stops without submitting its decision. By @crmne.
- **`reviews: off` written without quotes works.** YAML reads a bare `off` as false, which triage rejected. By @crmne.

Verified with RuboCop, 323 specs, 23 offline replays, and a live evaluation of gpt-oss-120b through OpenRouter.
