## New

- **CodeRabbit approvals reach the board.** When CodeRabbit finds nothing, it used to post only a summary comment, which triage skips like any bot comment, so a clean pull request stayed where it landed. With `request_changes_workflow: true` in `.coderabbit.yaml`, CodeRabbit approves a clean pull request, and an approved, green, mergeable one goes to Sign off. By @crmne.
- **Requested changes are weighed, not obeyed.** CodeRabbit requests changes for any finding, nitpicks included, so its "changes requested" now goes to the agent, which applies the same rules as for every finding: real problems go back to the author, nitpicks do not. The agent sees each bot's latest verdict next to its findings. By @crmne.
- **The film shows review bots.** A new beat shows a clean, approved pull request coming to Sign off while one with a real problem goes back to its author. By @crmne.

## Changes for existing workflows

Workflows on `crmne/copilot-triage@v0` receive this release automatically.

- **To get CodeRabbit approvals,** add this `.coderabbit.yaml` to your repository:

  ```yaml
  reviews:
    profile: chill
    request_changes_workflow: true
  ```

  CodeRabbit's approval then counts as an approving review on GitHub; you still merge.

Verified with RuboCop, 311 specs, 23 offline replays, and the configuration rolled out to our repositories, where CodeRabbit approved the clean pull requests and requested changes on the others for minor findings, exactly the kind the agent now weighs instead of obeying.
