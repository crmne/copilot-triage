Fixes a v0.8.2 regression: adding the Done column cleared every card's column on existing boards.

## Fixed

- **Cards keep their columns when the board changes.** Setting up the board rewrote its columns without their IDs, which makes GitHub recreate them and clear them from every card. v0.8.2's new Done column therefore emptied every column on boards set up by v0.8.0 or later. Existing columns now keep their IDs; boards emptied by v0.8.2 are filled again by the next sweep, and priorities and next steps were never affected. By @crmne.
