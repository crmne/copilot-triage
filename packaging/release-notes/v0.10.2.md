Duplicates close again, however detailed the newer report is.

## Fixed

- **A newer duplicate is closed, even when it is the more detailed report.** v0.10.1 kept a duplicate open as related whenever it had more detail than the older issue or carried a pull request's discussion. Newer duplicates are often the more detailed ones, so that kept real duplicates open. It is removed: a duplicate closes in favor of the older issue, and the pull request keeps its own discussion. By @crmne.
- **A duplicate's comment no longer contradicts the closure.** It explains the overlap with the older issue and never suggests keeping the report open or closing the other one. By @crmne.

Verified with RuboCop, 310 specs, 23 offline replays, and a live evaluation of the default model at 23 of 23, with both duplicate cases closed.
