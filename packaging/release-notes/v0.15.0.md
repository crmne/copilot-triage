## New

- **A shared workflow to call.** A repository's workflow can now name its events and call `crmne/copilot-triage/.github/workflows/assess.yml@v0` with `secrets: inherit`, and the board's sweep calls `sweep.yml@v0`. Permissions, queueing, inputs, and secrets live in Copilot Triage and update with the tag. See the README. By @crmne.
- **Shared policies.** `extends: owner/repo:path` in `.github/triage.yml` inherits another policy's settings, section by section, with the repository's own keys winning. By @crmne.
- **Copilot reviews for private repositories only.** `pull_requests.reviews: private` keeps Copilot's reviews, billed to you, for private repositories, when a free bot such as CodeRabbit reviews the public ones. By @crmne.

## Fixed

- **Closing an issue or pull request moves its card to Done.** Since v0.12 the step that handles closes never received the project token, so every close was skipped and cards waited for the daily sweep. Your own pull requests are placed from events again for the same reason. By @crmne.
- **The sweep's requests for the agent's judgment run.** The workflow skipped events sent by bots, and the sweep's request is one, so fork pull requests that needed a closer look never got it. By @crmne.
- **New pull requests get a card.** CodeRabbit adds its summary to a description seconds after a pull request opens, which looked like the author changing the report, so triage gave up. Its summary is now left out. By @crmne.
- **Your placements in Sign off stay.** v0.12 treated any comment of yours as answering a closure proposal, even one written before it, and moved cards you had placed yourself. Only a reopen or a comment after the card was placed counts now. By @crmne.
- **Cards the sweep moves get a fitting next step,** such as "Conflicts with the base branch: the author rebases", instead of the one written for their old column. By @crmne.
- **A pull request parked in Decide goes back to its author** once it stops being mergeable. By @crmne.

## Changes for existing workflows

Workflows on `crmne/copilot-triage@v0` receive this release automatically. To stop maintaining permissions and secrets in each repository, switch your workflows to the shared ones shown in the README.

Verified with RuboCop, actionlint, 331 specs, 23 offline replays, and a cross-repository run of the shared workflow, which received the calling repository's secrets and variables.
