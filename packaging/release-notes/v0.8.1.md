Triage now recovers from Copilot sessions that end without doing anything, which left about one in five assessments for the maintainer, and most of them when many pull requests open at once.

## New

- **Quiet assessments.** `quiet: true` writes only to the board, with no comments, labels, closures, or Copilot reviews, for installing triage on a repository with existing reports and sorting them without pinging anyone. By @crmne.

## Fixed

- **Fewer assessments left for the maintainer.** When many runs start together, some Copilot CLI sessions end within seconds without calling a single tool. Such a session changed nothing, so triage now tries again after 20 and then 40 seconds. A session that used any tool is never retried. By @crmne.
- **Clearer failures.** When every attempt fails, the job summary now includes the model's final text, so the cause is visible. By @crmne.

## Known limitations

- Retries add up to a minute to a failing run. If Copilot stays unavailable, the report is still left for the maintainer, unchanged.
