Copilot Triage is now a maintainer's copilot for all of GitHub, not just issues. It triages pull requests, moves discussions that are really bug reports to issues, reads whole conversations, and keeps a project board of what actually needs you, so you can turn off GitHub's email and open the board instead. It also runs on your own API key through RubyLLM, and the README now publishes how each model does on our evaluations.

## New

- **A board of whose move it is.** Every issue and pull request lands on a GitHub project board by whose move it is (Needs me, Waiting on them, Ready to merge, In progress, Backlog), with a priority and a one-line next step written for you. Urgent items are assigned to you, which is the one notification you get. A daily sweep without a model adds existing items and moves cards as facts change, and cards you move yourself stay where you put them. Opt in with a `board` section and a project token. By @crmne.
- **Pull request triage.** With a `pull_requests` section, pull requests are assessed when they open, reopen, become ready, or get a comment. The agent reads changed files through the API, never contributor code, requests a Copilot code review when a change deserves one (again after new pushes, once per commit), applies your contribution policy, and explains or, if you choose, closes changes your documented scope rules out. By @crmne.
- **Discussions that are really issues become issues.** A new discussion that is a reproducible bug report or a concrete feature request is copied into an issue that credits and mentions the author, linked, and closed as outdated. Questions stay in discussions, where the bot answers them. By @crmne.
- **Your own API key.** `engine: rubyllm` runs a [RubyLLM](https://rubyllm.com) agent with the same prompt, tools, and checks, for a company key, OpenRouter, a cloud provider, a local model, or any OpenAI-compatible endpoint. Replies show the run's cost when the price is known. By @crmne.
- **Published evaluations.** The README now lists live results for the default model, other Copilot models, and local models: GPT-5.6 Luna passed 29 of 30 cases, and the cheaper or local alternatives we tried missed far more. By @crmne.
- **`reasoning-effort: default`** for models that take no reasoning setting, such as Claude Haiku. By @crmne.

## Changes for existing workflows

Workflows on `crmne/copilot-triage@v0` receive this release automatically.

- **Discussions move to issues by default.** Set `discussions: move_to_issues: false` in your policy to keep every discussion where it is.
- **Whole conversations are read.** The agent now sees up to the latest 100 comments instead of 5. A long thread costs more tokens, around a cent with the default model.
- **The board and pull request triage are opt-in.** Nothing changes until you add their policy sections and workflow triggers; see the README.

## Fixed

- **Long threads are assessed instead of skipped.** Reports over the old 24 KB starting prompt, such as long pull request threads, were left for the maintainer. Only a single text over 30 KB, such as a pasted log, is now shortened, around a visible marker. By @crmne.

## Known limitations

- GitHub has no API to convert a discussion, so the new issue is opened by the workflow's bot and its author cannot edit it.
- Fine-grained tokens cannot reach user-owned projects yet, so the board needs a classic token with the `project` scope. GitHub's API also cannot enable a project's built-in workflows; turn on **Item closed** and **Pull request merged** in the project settings.
- Small and local models fail most evaluation cases, and Gemini 3.6 Flash did not finish within Copilot CLI's 90-second limit. Measure a model before you rely on it.
- A Copilot CLI session can still occasionally end without a decision. Those runs fail visibly and change nothing.

Verified with RuboCop, 260 specs, 15 offline replays, live dry runs on real RubyLLM and Spotifast issues, pull requests, and discussions, a live board sweep against a private test project, and a final live evaluation of the default model (14 of 15).
