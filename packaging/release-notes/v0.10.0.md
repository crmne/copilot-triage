Triage now weighs what every review bot finds, and asks Copilot only where it pays off. We classified 693 findings from Copilot and CodeRabbit across 196 pull requests: the two bots catch different problems, and Copilot finds little that matters on small changes.

## New

- **Findings from every review bot.** The agent reads each finding Copilot and CodeRabbit leave on the latest commit, with its file, the bot's severity label, and an excerpt, and weighs it on its own. Races, data loss, broken migrations, security problems, and findings rated high or major send a pull request back to its author. Documentation, translation, and style remarks, nitpicks, and low-rated findings never do. By @crmne.
- **CodeRabbit runs triage.** A CodeRabbit review triggers triage like a Copilot review, and the daily sweep sends fork pull requests with CodeRabbit findings to the agent, once per review. By @crmne.
- **Copilot only on changes worth it.** Triage requests a Copilot review only when a change has at least 100 lines of code (`pull_requests.review_min_lines`). Documentation, translations, workflows, lockfiles, and media do not count. In the study, Copilot's findings on smaller changes were mostly noise. By @crmne.
- **A quota message is not a review.** When Copilot only says it could not review, for example because the requester's quota ran out, triage treats the pull request as unreviewed instead of clean. In the study, 28% of Copilot's reviews on other projects were such messages. By @crmne.

## Changes for existing workflows

Workflows on `crmne/copilot-triage@v0` receive this release automatically.

- **CodeRabbit is optional.** Install the [CodeRabbit app](https://coderabbit.ai) to get its reviews; it is free for public repositories. Without it, nothing changes except the 100-line rule for Copilot.
- **Fewer Copilot reviews.** Small changes no longer get one. Set `pull_requests.review_min_lines: 0` to keep the old behavior.

## Known limitations

- Severity labels are read from the start of each finding; a bot that labels findings differently is still weighed by the agent, just without the label.
- The study's judgments come from one rater, and its head-to-head sample leans on a few repositories.

Verified with RuboCop, 309 specs, 23 offline replays, a live read of CodeRabbit findings on a real pull request, and a live evaluation of the default model: 23 of 23 cases, including the eight pull requests whose Copilot verdict was "needs a closer look".
