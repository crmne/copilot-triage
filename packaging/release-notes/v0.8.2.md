Finished work now shows up in a **Done** column the moment it closes or merges, so you can see what got done this week, and leaves the board after a week. Reopened issues and pull requests come back.

## New

- **Done, then archived.** Closing an issue or merging a pull request moves its card to Done right away, without a model call. The daily sweep archives cards that have been in Done for `archive_after_days` (7 by default; 30 keeps a month). Archived cards stay searchable in the project. By @crmne.

## Fixed

- **Reopened work comes back.** A reopened issue or pull request is brought back from the archive and placed in the right column again, instead of staying hidden. By @crmne.
- **Merged pull requests no longer wait a day.** Until now, finished work left the board only at the next daily sweep. By @crmne.

## Changes for existing workflows

- Add `closed` to the `issues` and `pull_request_target` types of the triage workflow so cards move to Done immediately; see the README. Without it, the daily sweep still moves them.

## Thanks

- @crmne for the Done column and the reopen handling.
