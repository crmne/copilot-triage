Triage works again on private repositories.

## Fixed

- **Private repositories are triaged again.** v0.9.0 read every pull request's check status in its main query, which a private repository's workflow token may not be allowed to do, so triage failed on every issue and pull request there. The check status is now read separately, only for your own pull requests, and when it cannot be read the pull request goes to Do instead of being taken for green. By @crmne.
