Fewer failed runs, and no more closing the better of two duplicate threads.

## Fixed

- **An inconsistent decision no longer fails the run.** When the agent named a relationship without the related issue, linked an issue without explaining why, or cited sources without a comment, the run failed after the model had finished, leaving the item for you. The decision tool now sends these back to the agent, which corrects them in the same session. Five of 116 runs in a one-time pass over every open issue failed this way. By @crmne.
- **The better thread stays open.** A report that is more detailed than the one it duplicates, or that carries the discussion for an open pull request, is now linked as related instead of closed. Triage had closed such a design discussion as a duplicate of an older, thinner request. By @crmne.
- **Copilot's verdict comes before finding labels.** When Copilot's reason names something still wrong, the pull request goes back to its author even if its individual findings are rated low. One evaluation case had started to wobble on this since v0.10.0. By @crmne.

Verified with RuboCop, 310 specs, 23 offline replays, and two live evaluations of the default model at 23 of 23, with the wobbling case passing three reruns in a row.
